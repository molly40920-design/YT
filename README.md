# 快速建立廣告 — 互動 Demo（XMP 移植）

參考 XMP（mobvista）的「一鍵交叉建立廣告」功能，移植於自有平台的互動原型。
三欄式建立工作區：左欄步驟導航、中欄動態表單（連動防呆）、右欄即時拆分規則。
支援 **Meta／Google／TikTok／ASA／AppLovin** 五套流程。

## 線上檢視

單一檔案、零安裝；React、Babel、Tailwind 由 CDN 載入，圖示為內嵌 SVG。

1. **直接下載開啟**：下載 `index.html`，用瀏覽器打開即可（需連網以載入 CDN）。
2. **GitHub Pages**：推上 GitHub → Settings → Pages → 選 branch / root → 儲存，之後用 `https://<帳號>.github.io/<repo>/` 開啟。

> GitHub 直接預覽 `.html` 只顯示原始碼；要看實際畫面請用上述任一方式於瀏覽器執行。

## 平台切換

於 **基礎設置** 的「投放平台」欄位選擇 META／Google／TikTok／ASA／Applovin 即切換對應流程（五媒體全數實作；TikTok／ASA／Applovin 欄位規格依 2026/8 於 XMP 實際頁面盤點結果仿製）。

- **Meta（9 步）**：基礎設置 → 廣告系列 → 投放內容 → 地區組 → 版位 → 定向包 → 出價和預算 → 創意設置 → 創意組。四個多組合模組（地區組／定向包/出價和預算/創意組）皆拆分於「廣告組」層。iOS 14+、CBO、成效目標×出價策略等連動完整。
- **Google UAC（5 步）**：基礎設置 → 地區組 → 出價和預算 → 廣告組 → 創意組。兩個多組合模組：地區組（拆分於「廣告系列」層，上限 100）、創意組（拆分於「廣告組」層，上限 50）。成效目標（安裝量／應用內操作次數／應用內操作價值 tROAS）連動出價與欄位。
- **TikTok（10 步，仿 XMP）**：基礎設置 → 推廣系列 → 投放內容 → 地區組 → 版位 → 定向包 → 出價和預算 → 創意設置 → 創意組 → 監測。四模組（地區組≤50／定向包≤20／出價和預算≤20／創意組≤50）皆拆分於「廣告組」。連動：CBO 開啟→預算鎖日預算、廣告組層隱藏預算/出價、優化目標剩 安裝/應用內事件、競價鎖最大投放量；優化目標切換→計費方式（CPC/oCPM）、事件/價值 ROAS 欄位、歸因窗口。
- **ASA（7 步，仿 XMP）**：基礎設置 → 地區組 → 預算 → 出價 → 關鍵詞 → 定向包 → 創意組。地區組/預算拆分於「廣告系列」，出價/關鍵詞/定向包/創意組拆分於「廣告組」。連動：選廣告系列組→自動帶推廣應用（未選時定向包/創意組隱藏）；受眾=自定義→展開設備/用戶類型/性別/年齡/時段；素材=自定義→CPP 下拉。
- **Applovin（6 步，仿 XMP）**：基礎設置 → 投放內容 → 地區 → 出價和預算 → 創意組 → 追蹤鏈接。單一 Campaign＋創意組（≤100）。連動：出價類型（CPI/CPE/CPP/AD_ROAS/CHK_ROAS/BLD_ROAS）→目標時間窗（DAY 0 ↔ DAY 7/28）與出價單位（USD ↔ %）；出價/預算支援分地區。

> 註：CDN 的 Babel 已鎖定版本 `@babel/standalone@7.24.7`（新版預設改用 automatic runtime 會導致頁面空白，勿改回未鎖版本）。

## 預覽

點「預覽」列出即將生成的每個廣告組（狀態可切換）；「操作」可**複製**（下方插入 `_copy` 列）與**刪除**，摘要數字即時更新。
